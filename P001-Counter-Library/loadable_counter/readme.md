# P001.4 - Loadable Counter

## Overview

A synchronous 4-bit Loadable Counter implemented in Verilog HDL.

The counter supports synchronous reset, parallel data loading, counting, and hold functionality.

---

## Features

- 4-bit Counter
- Parallel Load
- Synchronous Reset
- Enable Control
- Count Operation
- Hold State
