# P001.5 - Parameterized Counter

## Overview

This project implements a reusable synchronous parameterized counter in Verilog HDL.

The counter width can be configured during module instantiation using a Verilog parameter.

---

## Features

- Parameterized Counter Width
- Synchronous Reset
- Enable Control
- Reusable RTL IP
- Positive Edge Triggered
