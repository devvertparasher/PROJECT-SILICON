# P001.2 — Down Counter

## Description

A synchronous 4-bit down counter written in Verilog.

---

## Features

- Positive edge triggered
- Active-high synchronous reset
- Enable control
- Counts from 15 to 0

---

## Tools

- VS Code
- Icarus Verilog
- GTKWave
- Yosys
